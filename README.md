# Projeto de cadastro de produtos
Projeto desenvolvido em **Java**, utilizando **Programação Orientada a Objetos (POO)**, manipulação de arquivos e tratamento de exceções.

---

## Objetivo
Este projeto foi desenvolvido com o objetivo de praticar conceitos estudados durante o curso, implementando um **CRUD (Create, Read, Update, Delete)** com persistência de dados em arquivo **CSV**.

Principais tópicos aplicados:
- Programação Orientada a Objetos (POO)
- Persistência de dados em arquivo
- Tratamento de exceções
- Organização e estruturação de código

---

## Funcionalidades
O sistema permite o cadastro de produtos via console, armazenando as informações em um arquivo `.csv`.

- Criar registros  
- Listar dados cadastrados  
- Atualizar informações  
- Remover registros  

---

## Aprendizados
- Estruturação de um CRUD
- Manipulação de arquivos
- Uso de listas (ArrayList) para controle dos regitros
- Tratamento de exceções
